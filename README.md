# goit-markup-hw-05

Add layout and design of layout forms

https://www.figma.com/design/wuEpGhwCepGCOUw7mZFRac/Web-Studio-(Version-5.0)?node-id=297035-1582&p=f&t=dQsJYG7LoXGYYrAP-0

Criteria for acceptance of work by a mentor

Project

«A1» All styles are written in one file styles.css, which is located in the css folder.
«A2» The source code is formatted using Prettier.
«A3» All images and text content are taken from the layout.
«A4» The modern-normalize style normalizer is connected
«A5» The code is written in compliance with the guidelines.

Modal window

«B1» The layout and design of the “backdrop” (dark translucent background) of the modal window is completed.
«B2» The “backdrop” fills 100% of the height and width of the browser viewport and is fixed in it.
«B3» The layout and design of the modal window is completed.
«B4» The modal window is vertically and horizontally positioned in the middle of the backdrop.
«B5» The markup and design of the modal window close button in the upper right corner is completed.
«B6» Initially, the modal window and backdrop are hidden.
«B7» If you add the is-open class to the backdrop element, the backdrop and modal window appear.

Forms

«C1» The HTML markup of all layout elements is completed.
«C2» Tags are used according to their semantic content.
«C3» The markup of the newsletter subscription form and all its elements in the footer is completed.
«C4» The markup of the application form and all its elements in the modal window is completed.
«C5» All inputs in the forms have a name attribute.
«C6» The value of the name attribute is descriptive, accurately characterizing what this form field is for.
«C7» All inputs have an associated <label> element.
«C8» Inputs are assigned a placeholder attribute, if there is a tooltip text for it in the layout.
«C9» Form “submit” buttons are assigned a type="submit" attribute.
«C10» All new icons from forms are added to the SVG sprite icons.svg.

Design

«D1» The elements of the newsletter subscription form in the footer are designed.
«D2» The elements of the application form in the modal window are designed.
«D3» When the input receives focus, its frame and icon change color (as shown in the layout).
«D4» The original checkbox about accepting the license agreement in the application form is hidden.
«D5» The design of the “checkbox” about accepting the license agreement is done manually, using a vector image of a checkmark from an SVG sprite.
«D6» Transitions are made for all hover and focus effects (color, background, shadow). time — 250ms, time distribution function — cubic-bezier(0.4, 0, 0.2, 1).
